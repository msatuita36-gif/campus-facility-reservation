# Campus Facility Reservation & Decision Support System

A Streamlit prototype based on the uploaded `midterm.ipynb` and `facility_reservations (1).xlsx`.

## Five working modules
1. Overview Dashboard — total bookings, observed completion, facility counts.
2. Reservation Data Explorer — filter and download reservation records.
3. Completion Prediction — estimate Completed vs Not Completed for a proposed booking.
4. Risk & Pattern Analysis — compare observed rates and view hold-out metrics/confusion matrix.
5. Decision Support Recommendations — provide review prompts grounded in observed rates.

## Run locally
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
The app reads `facility_reservations.csv` from the same folder.

## Deploy to Streamlit Community Cloud
1. Create a GitHub repository and upload the project files.
2. In Streamlit Community Cloud, select **New app**, connect the repository, branch, and `app.py`.
3. Deploy. The resulting public URL is generated by Streamlit; it cannot be created from this local package.
4. Test each module and record screenshots for the submission.

## Important
The model predicts a combined `Not Completed` class for records whose `Usage_Status` is Cancelled or No-Show. It is a prototype for decision support, not an automated booking-denial system. Review model performance and data governance before real-world use.
